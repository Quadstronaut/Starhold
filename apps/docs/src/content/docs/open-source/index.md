These are **Quadstronaut projects**: personal open-source work by our operator. They are not Starhold products. Starhold is proud to surface utilities that solve real problems and happen to come from the same shop.

## QuadClicker

A fast, native, open-source auto-clicker for Windows, macOS, and Linux. Three separate native applications — WPF/C# on Windows, SwiftUI/Swift on macOS, Qt6/C++ on Linux — with no cross-platform frameworks and a full CLI mode alongside the GUI.

[Read the QuadClicker docs →](/open-source/quadclicker/)

## Source coming soon

Two more projects are listed in the open source section of [starhold.dev](https://starhold.dev/#open-source). Neither has public source yet.

- **Peridot.** A private period tracker for Android. Everything stays on your phone. Free. Coming soon: it is not released yet. Source coming soon. Its [terms of use](https://starhold.dev/peridot/terms) are already published.
- **Circle.** A tool that has AI assistants from different companies work on the same task together. In development. Source coming soon.
