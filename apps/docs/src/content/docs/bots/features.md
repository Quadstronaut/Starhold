The full Discord Bots feature set. Two flat prices, nothing metered: **$5/mo per bot** covers everything below except the Ops Pack, plus an optional **$9/mo Ops Pack** ($14/mo all-in) for the monitoring features. Your name and avatar on the bot, hosting included. For the ordering flow and roadmap policy, see [How Ordering Works](/bots/ordering/).

## Community — $5/mo

| Module | What it does |
|---|---|
| Moderation | Kick/ban/timeout, word filters, anti-spam, raid protection |
| Welcome & Roles | Greetings, autorole, reaction/button roles |
| Logging & Audit | Message, member, and mod-action logs to channels you pick |
| Leveling & Engagement | XP, ranks, leaderboards, level-up announcements |
| Giveaways & Events | Timed draws with entry requirements and rerolls |
| Suggestion Boards | Suggestion channels with reaction-vote tallies |
| GitHub Activity | Streams members' GitHub commits — author, date, messages, count |

## Automation & Integrations — $5/mo

More than a generic automation plan, at the base price.

| Module | What it does |
|---|---|
| Scheduled Tasks | Cron jobs: recurring posts, digests, reminders |
| Forms & Tickets | Intake forms routed to threads; ticketing workflow |
| Approval Flows | Button/select-driven approval and request workflows |
| Data Sync | Read/write Google Sheets, Notion, or a database |
| Integration Relays | GitHub, CI, Stripe, and webhook events into your channels |
| Alerts & On-Call | Threshold alerts with escalation and mentions |

## Ops Pack — +$9/mo

Infra-heavy monitoring; adds $9/mo per bot ($14/mo all-in). Heavy use — many monitors, sub-minute intervals, JS/proxy scraping, or paid third-party API quotas — is scoped via [Server/Task Automation](https://starhold.dev/services/automation).

| Module | What it does |
|---|---|
| Server Monitoring | Uptime plus CPU/RAM/disk alerts for your servers |
| Application Monitoring | Health checks, error/latency alerts, deploy pings |
| Scheduled Scraping | Watch a page or API on a schedule, post changes |

## Custom Commands — $5/mo

| Module | What it does |
|---|---|
| Custom Commands | Your own slash commands and canned replies — anything else |
