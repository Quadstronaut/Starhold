We host and operate these services for people who care where their data goes. Most of it is **under development**, and some of it is **invitation only**. Each page says what the service does today, how to get in, and which of the [Starhold rules](/) it already meets.

| Service | What it is | State today |
|---|---|---|
| [Umbermark](/services/umbermark/) | Scored server hardening report with a shareable link | Open · early access, paid plans |
| [Zenithmark](/services/zenithmark/) | Mail and DNS scorecard for a domain | Open · free |
| [Starhold Render](/services/render/) | OG image, PDF and screenshot API | Invitation only |
| [Starhold Status](/services/status/) | Private and white-label status pages for MSPs | Invitation only |
| [Starbot](/services/starbot/) | Discord assistant for the Starhold community | In development |
| [Shushgame](/services/shushgame/) | The quiet game on Discord | Open · free |
| [QNix](/services/qnix/) | Personal hosting, built to be hard to break | In development |

## Getting in

Sign-in is closed until Starhold Account opens, and checkout is paused. Invitations are sent by hand: ask, and we send your link. Use the contact form at [starhold.dev/contact](https://starhold.dev/contact?intent=invite) or write to [hello@starhold.dev](mailto:hello@starhold.dev).

Whether each service is up right now: [Fleet status](https://status.starhold.fyi).
