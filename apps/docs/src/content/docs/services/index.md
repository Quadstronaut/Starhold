Starhold hosts and operates these services for people who care where their data goes. Everything is **under development**, and most of it is **invitation only**. Each page says what the service does today, how to get in, and which of the [Starhold rules](/) it already meets.

| Service | What it is | State today |
|---|---|---|
| [Umbermark](/services/umbermark/) | Scored server hardening report with a shareable link | Live, early access |
| [Zenithmark](/services/zenithmark/) | Mail and DNS scorecard for a domain | Live, free, in development |
| [Starhold Render](/services/render/) | OG image, PDF and screenshot API | Invitation only, in development |
| [Starhold Status](/services/status/) | Private and white-label status pages for MSPs | Invitation only, in development |
| [Starbot](/services/starbot/) | Discord assistant for the Starhold community | In development |
| [Shushgame](/services/shushgame/) | The quiet game on Discord | Live, free |
| [QNix](/services/qnix/) | Encrypted, multi-tenant hosting platform | Paused |

## Getting in

Sign-in is by invitation: ask, and I send your link. Use the contact form at [starhold.dev/contact](https://starhold.dev/contact?intent=invite) or write to [hello@starhold.dev](mailto:hello@starhold.dev).

Whether each service is up right now: [Fleet status](https://status.starhold.fyi).
