**A Discord assistant for the Starhold community.**

- **State:** In development.
- **Availability:** In development.
- **Where:** the [Starhold Discord](https://discord.gg/Ug8CM86Bxv)

## How to get in

Join the [Starhold Discord](https://discord.gg/Ug8CM86Bxv). Starbot is being built there, in the open; it is not open to use yet.

## Fair terms and privacy defaults

Starbot runs under the same [Starhold rules](/) as every other service. Questions about what it holds: use the [contact form](https://starhold.dev/contact) or write to [hello@starhold.dev](mailto:hello@starhold.dev).

## What Starbot keeps

As built today, Starbot keeps the server settings and Discord ids its features need to work, and contact notices. It has no automatic deletion yet: a 12-month purge of contact notices is not built. Ask and it is deleted by hand. The privacy policy lists this as built today.

Starbot is not the retired custom-bot subscription.

## Not there yet

- **A full write-up of what Starbot holds, and self-serve export and delete,** are not done yet. Export and delete are by request to privacy@starhold.dev, done by hand within 30 days.
